### 🚀 About The Project
This project is a classic 3D raycasting engine inspired by the original DOOM, developed entirely in Python using the Pygame library. It features custom map rendering, raycasting mechanics, texture mapping, sprite handling, pathfinding, and interactive enemies/weapons.

---

### 📂 Project Structure
* `main.py` — The core game loop and entry point.
* `map.py` — Map layout and grid definitions[cite: 2].
* `raycasting.py` — Raycasting engine implementation for 3D perspective[cite: 2].
* `player.py` — Player movement, rotation, and controls[cite: 2].
* `npc.py` — Enemy logic and behavior[cite: 2].
* `weapon.py` — Weapon animations and rendering[cite: 2].
* `pathfinding.py` — AI navigation and pathfinding logic[cite: 2].
* `object_renderer.py` & `object_handler.py` — Rendering management for game objects[cite: 2].
* `settings.py` — Game configurations (resolution, speed, colors)[cite: 2].
* `sound.py` — Sound effects and background audio management[cite: 2].
